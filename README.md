# RoboForge (working name)

A free, open-source, offline-first desktop app for learning robotics — electricity, circuits, Arduino, motors, and your first robot — with built-in simulators and a local, Socratic AI coach.

- **Free forever. No accounts. No tracking. Runs on your machine.**
