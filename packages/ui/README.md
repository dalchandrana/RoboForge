# @roboforge/ui

Design system components and design tokens for RoboForge.
Enforces WCAG 2.2 AA accessibility, minimal touch target sizes (>= 40px), safety callout styling, and dark/light mode tokens.

## Usage

```tsx
import { Button, Callout, Card, Modal } from '@roboforge/ui';
import '@roboforge/ui/tokens.css';
```
