## 1. Hook: How Far Did the Robot Drive?
You program your robot to drive forward:
```cpp
setMotors(200, 200);
delay(3000); // Drive for 3 seconds
setMotors(0, 0);
```

Did the robot travel exactly $1.0\text{ meter}$?
- On slick tile, wheels slip and it travels $0.6\text{ m}$.
- On deep carpet, friction slows the wheels and it travels $0.8\text{ m}$.
- As the battery drains, it drives slower each minute.

Open-loop timing cannot measure movement accurately. To navigate reliably, a robot must measure the physical rotation of its wheels using **Rotary Encoders**!

<Callout type="safety" title="Rotating Mechanism Safety">
  When mounting slotted encoder discs to DC gearmotors, verify adequate clearance between the spinning disc and the chassis wall. Keep loose clothing, hair, and fingers away from spinning gears and wheels during testing.
</Callout>

## 2. Optical Slotted Encoders
The simplest encoder consists of:
1. **Slotted Code Wheel:** A black plastic wheel with 20 radial cutouts attached to the motor shaft.
2. **Optocoupler Sensor (Photo-Interrupter):** An infrared LED facing a phototransistor across an optical gap.

As the wheel spins, the solid spokes block the light (Output = LOW) and the slots let light through (Output = HIGH). Each rising edge equals one fractional turn!

### Calculating Distance:
If a wheel has 20 slots ($20\text{ pulses per revolution}$) and a diameter $D = 65\text{ mm}$:
$$\text{Circumference} = \pi \times D = 3.14159 \times 65\text{ mm} \approx 204.2\text{ mm}$$
$$\text{Distance per Pulse} = \frac{204.2\text{ mm}}{20} \approx 10.21\text{ mm per tick}$$

Every time the Arduino detects a pulse, the robot has moved forward by approximately $1\text{ centimeter}$!

## 3. Quadrature Encoding: Detecting Direction
A single sensor counts pulses, but cannot tell if the wheel is spinning **forward** or **backward**!

A **Quadrature Encoder** uses two sensors (Channel A and Channel B) placed out of phase by $90^\circ$ (a quarter-wave):

```
Forward:
Channel A:  ___|---|___|---|___
Channel B:  _____|---|___|---|__  (B lags behind A)

Reverse:
Channel A:  _____|---|___|---|__
Channel B:  ___|---|___|---|___  (B leads ahead of A)
```

By reading the state of Channel B at the exact moment Channel A transitions from LOW to HIGH:
- If B is LOW: Wheel is spinning **Forward**.
- If B is HIGH: Wheel is spinning **Backward**!

## 4. Hardware Interrupts
Because wheels spin fast (often generating hundreds of pulses per second), regular `loop()` code can miss pulses while busy calculating.

Microcontrollers use **Hardware Interrupts** (pins 2 and 3 on the Arduino Uno) that instantly pause normal execution, increment a counter in nanoseconds, and return to the main loop:

```cpp
volatile long pulseCount = 0;

void countPulse() {
  pulseCount++; // Runs instantly in hardware ISR
}

void setup() {
  pinMode(2, INPUT_PULLUP);
  // Trigger countPulse() on every rising edge of Pin 2
  attachInterrupt(digitalPinToInterrupt(2), countPulse, RISING);
}
```

## 5. Summary
- Rotary encoders provide closed-loop physical feedback on speed and distance.
- Quadrature phase encoding provides direction and 4x resolution.
- Hardware interrupts ensure no movement ticks are lost during computation.
